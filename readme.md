Portfólio Pessoal — Pâmela Sales

Portfólio pessoal desenvolvido como parte das atividades acadêmicas do curso de Análise e Desenvolvimento de Sistemas (ADS), com o objetivo de apresentar minha trajetória profissional, meus projetos e minhas habilidades em desenvolvimento web.

O projeto utiliza HTML5, CSS3 e JavaScript, com navegação entre cinco páginas, alternância de tema claro e escuro, validação de formulário e publicação pelo GitHub Pages.

📖 Descrição do projeto

O portfólio reúne informações pessoais, acadêmicas e profissionais, além de recursos de multimídia, gráficos e um formulário interativo.

O site foi desenvolvido com foco em organização do código, navegação, experiência do usuário e aplicação prática dos conhecimentos adquiridos durante o curso.

✨ Funcionalidades implementadas

1. Navegação entre páginas

O site possui cinco páginas HTML conectadas por um menu de navegação, permitindo acessar diferentes seções do portfólio.

2. Tema claro e escuro

Foi implementado um botão para alternar entre os temas claro e escuro.

A escolha do usuário é armazenada no localStorage, permitindo que o tema selecionado seja recuperado após atualizar a página ou navegar pelo site.

Como testar:

Abra o portfólio no navegador.

Clique no botão de alternância de tema.

Atualize a página.

Verifique se o tema escolhido permanece ativo.

Navegue entre as páginas e confirme a manutenção da preferência.

3. Validação do formulário

O formulário utiliza JavaScript para verificar os dados informados pelo usuário antes de apresentar a confirmação.

Entre os campos estão:

Nome.

E-mail.

Telefone.

Data de nascimento.

Senha.

Confirmação de senha.

O sistema apresenta mensagens de erro próximas aos campos e uma mensagem de retorno na própria página, sem utilizar alert().

Como testar:

Acesse a página do formulário.

Tente enviar o formulário com campos vazios.

Observe as mensagens de validação.

Informe senhas diferentes e verifique a mensagem apresentada.

Preencha os campos corretamente e envie.

Confira a mensagem de sucesso.

Observação: o localStorage é utilizado para guardar a preferência de tema. A validação do formulário, por si só, não significa que os dados preenchidos sejam armazenados permanentemente.

4. Organização dos arquivos

Os arquivos CSS e JavaScript estão separados dos documentos HTML, facilitando a manutenção e a reutilização do código.

O projeto também possui um arquivo .gitignore para evitar o versionamento de arquivos desnecessários.

🔄 Versionamento com Git

O projeto utiliza Git para registrar alterações realizadas durante o desenvolvimento.

Foram utilizados commits com mensagens descritivas, seguindo padrões como:

feat: implementação de funcionalidades.

fix: correção de problemas.

chore: organização e manutenção do projeto.

O repositório possui as branches main e feature/documentacao-formulario.

A entrega da CP3 foi identificada pela tag anotada cp3-entrega, associada ao commit 8cac1bf.
