# Portfólio Pessoal — Pâmela Sales

Site pessoal desenvolvido em HTML e CSS puros, reunindo apresentação profissional, projetos, currículo e um formulário de cadastro. Criado como parte da transição de carreira para a área de Tecnologia.

## 📖 Descrição

O portfólio é composto por uma página inicial (`index.html`) com apresentação, seção "Sobre" e grade de projetos, além de páginas complementares para currículo e formulário de cadastro. O visual segue uma identidade única em todo o site: fundo claro, barra de navegação e rodapé em azul-marinho, e botões de destaque em azul.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3 (Flexbox, variáveis CSS, responsividade)
- Google Fonts — Poppins e Inter

## ▶️ Como visualizar o projeto

1. Baixe ou clone a pasta `meu-projeto` mantendo a estrutura de arquivos acima.
2. Abra o arquivo `index.html` diretamente no navegador (não é necessário servidor ou instalação).
3. Use o menu de navegação no topo para acessar as demais páginas (Currículo, Formulário, etc.).
